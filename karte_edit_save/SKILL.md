# カルテ編集して保存する

## 対象

- スプレッドシートは atelier顧客データベースで、IDは `14XTckRGgkSI8TQay-eemw25183iHGz-LaNmC9fyVF7g` だよ。
- 編集するシートは `TimeTree編集` で、書き込み先は `TimeTree` シートだよ。
- 操作はユーザーのChromeで行うため、`browser.browse` で device ブラウザを使うよ。

## 決まった手順

- 入力・変更できるのは、黄色と緑のセルだけだよ。
- C1の年月を決めるよ。C2は件数だよ。
- C3の▼をクリックして人を選ぶよ。選んだあと、C3セルの内容が消えるまで待つよ。消えたら読み込み完了だよ。
- 請求書エリアのB50（内容）とC50（金額）には、最低限何か入れることが多いよ。
- C5の▼をクリックして保存するよ。終わったら、TimeTree側に反映できているか確認するよ。消費税や合計金額も見るよ。
  - 確認はAPIで数字を見るだけでいいよ。TimeTreeシートを画面で開いて細かく見せると、逆に遅くなるからだよ。
  - TimeTreeシートの該当行で、F列（請求額）、G列（支払済額）、Y列（TODO-No）、AY列（請求書No）を見るよ。
  - 消費税と合計は、TimeTree編集シートのC71（小計）・C72（消費税）・C73（合計）で見るよ。

## ウェブアプリで操作する方法（2026-11-27に確認）

- TimeTree編集は、ウェブアプリのURLへGETすることでも操作できるよ。セルに直接書く必要はないよ。
- ベースURLは `https://script.google.com/macros/s/AKfycbw0xvM-620l1MwSccqYieFewNR-K20etKAIj1K-Cp6Hg5UQnrvpj2r4PmIi0fl3Jw9A/exec` だよ。
- 読み込みは `{URL}?action=load&label=...` をGETで呼ぶよ。curlでは `-G --data-urlencode` を使うよ（例：`curl -sL -G "{URL}" --data-urlencode "action=load" --data-urlencode "label=2026/11/25 13:30 タロ.AI"`）。labelはC3の一覧と同じ文字列（日時＋半角スペース＋名前）だよ。成功すると `{"ok":true,"action":"load","result":{"label":"...","row":9,"karteId":"6"}}` が返るよ。
- 保存は `{URL}?action=save` をGETで呼ぶよ。成功すると `{"ok":true,"action":"save","result":{"karteId":"6"}}` が返るよ。
- POSTで呼ぶと411エラー（Length Required）になるよ（2026-11-27に確認）。GETで呼ぶこと。
- `ok:false` のときは、errorの内容をユーザーに伝えるよ。
- 社長には action や URL を書かせないよ。自然な言葉から label を組み立てて、load → 必要なら編集の説明 → save の順に進めるよ。
- 読み込みは約9秒、保存は約10秒で終わるよ（2026-11-27にGETで確認）。

## ウェブアプリの読み込みでの注意

- ウェブアプリのloadでは、情報エリア（名前・日時・氏名・カルテID・データ行）は読み込まれるけど、TODOと請求書の内容は編集画面に戻ってこないよ。B30・B48も空のままで、情報エリアの請求額も0と表示されるよ。
- だから、すでに入っている行を読み込んで、そのまま保存すると、TODOと請求書が消えてしまうかもしれないよ。まだ確認していないことだよ。
- 保存する前には、C32・B50・C50に内容が入っていることを確認するよ。空のまま保存しないよ。

## 手順の進め方

- `TimeTree編集` シートを開くよ。
- C1に開始月（例：`2026/11`）、C2に件数（例：`100`）が入っていることを確認するよ。
- C3の▼から「教室日時 TimeTree名」の形の授業を選ぶよ。
- 読み込んだ情報エリアが、選んだ授業と合っているか確認するよ。TimeTree名、教室日時、氏名、カルテID、データ行の5つを見るよ。1つでも違っていたら編集せずに止まるよ。
- 編集する欄だけを変更するよ。ほかのセルは触らないよ。
- C5で「保存」を選ぶよ。D5に「保存成功」と出れば保存できたことになるよ。
- 保存できたら、Google SheetsのAPIで `TimeTree` シートの該当行を読み、変更が反映されたか確認するよ。

## APIでできないこと

- C3へのAPI入力では、授業の読み込みは動かないよ。C3に値を入れても、30秒待っても消えず、読み込みも始まらなかったよ（2026-11-22に確認）。
- C5へのAPI入力でも、保存は動かないよ。C5に「保存」と入れても、30秒待っても消えず、D5も変わらなかったよ（2026-11-22に確認）。
- 理由は、GASのonEditは人が画面で操作したときだけ動き、APIからの書き込みでは動かないからだよ。
- だから読み込み（C3）と保存（C5）はブラウザでやるか、ウェブアプリへPOSTしてやるよ。文字の入力だけAPIでやるよ。

## TODOと請求書を入れるとき

- TODOは、TODO入力エリアのTODO-1の行（32行目）のTODO内容のセル（C32）に入れるよ。
- TODOを複数入れるときは、TODO-2は33行目（C33）、TODO-3は34行目（C34）と下へ続けていくよ。保存すると、TimeTreeのTODO列に「:」付きで改行つなぎで入るよ（2026-11-22に2件で確認）。
- 請求書は、請求書入力エリアの内容入力1の行（50行目）の内容のセル（B50）と金額のセル（C50）に入れるよ。
- 請求書を複数入れるときは、内容入力2は51行目（B51・C51）、内容入力3は52行目（B52・C52）と下へ続けていくよ。小計・消費税・合計は全部の行で計算されるよ（2026-11-22に2件で確認）。
- 金額を入れると小計と消費税10%と合計が計算され、情報エリアの請求額に合計が表示されるよ。
- 保存すると、TODO-Noは「T-カルテID」、請求書Noは「INV-日付-カルテID」と自動で付くよ。
- 保存すると、`TimeTree` シートのTODO列と請求額列へ反映されるよ。TODOの表示には先頭に「:」が付くことがあるよ。

## C3の選択肢に出ないとき

- C3の選択肢に出るのは、`TimeTree` シートの氏名（C列）が入っている行だけだよ。
- 氏名が空の授業は、C3に出てこないよ。授業が無いと思って探し回らないよ。
- 表示が古いままのときは、メニュー「TimeTree編集」から「C3の表示データ初期化を再設定」を実行してから、もう一度C3を開くよ。
- それでも出ないときは、TimeTreeシート側にその授業の行があるか、氏名が入っているかを確認するよ。

## C3は選んだあと空になる

- C3は授業を選んだあと、自動で空になる仕組みだよ。読み込んだ内容は情報エリアに残るよ。
- 授業が読み込めているかは、情報エリアの表示（TimeTree名、教室日時、氏名、カルテID、データ行）で確認するよ。C3の値では確認しないよ。
- C3を選び直すと、入力中のTODOと請求書の内容が消えることがあるよ。保存前にはC3を触らないよ。

## 速く入力する方法

- 文字の入力は、ブラウザで1セルずつ打つより、Google SheetsのAPIで直接書き込む方が速いよ。
- 流れは、ブラウザでC3から授業を読み込む、APIでTODOと請求書のセルへ書き込む、ブラウザでC5を押して保存する、の3段階だよ。
- APIで書いても、請求額の計算式は自動で計算されるよ。TODO-Noと請求書Noは、保存時に自動で付くよ。
- APIで書いたあとにC3を選び直してはいけないよ。入力した内容が消えるからだよ。

## 予約とまとめて入力するとき（2026-11-27に確認）

- 予約を入れて、そのままTODOと請求書まで入れることもできるよ。流れはこうだよ。
- 1. 「予約を入れる」で input01 を呼ぶよ。
- 2. 自動の取り込みを待って、TimeTreeシートに行ができたのを確認するよ。手動の取り込み（scrape01）は呼ばないよ。時間がかかるからだよ。行ができたら、`TimeTreeデータ登録` の2行目を空にするよ。行がなかなかできないときは、タロちゃんに聞いてから手動で呼ぶよ。
- 3. ウェブアプリの load（GET）で読み込むよ。
- 4. B18（制作物）に作品名を入れるよ。予約のときのメモ（作業内容）と同じものを入れるよ。保存するとTimeTreeシートのI列（制作物）に入るよ。
- 5. TODO（C32〜）と請求書（B50・C50〜）をAPIで書き込むよ。
- 6. ウェブアプリの save（GET）で保存するよ。
- 新しい予約なら、loadでTODOと請求書が戻ってこない問題は起きないよ。まだ何も入ってないからだよ。
- 確認した例：2026-11-27に「2026/11/25 13:30 タロ.AI ステンドグラス」で試したよ。カルテIDは2、データ行は5。B18にステンドグラス、TODO 3件（事前準備A・B・C）と請求書3件（A 1,000円・B 2,000円・月謝 5,000円）を入れて保存し、TimeTreeシートに制作物ステンドグラス、請求額8,800円、TODO-No T-2、請求書No INV-2026-11-24-2 が付いたよ。

## テスト編集の扱い

- テストで入れた文字は、確認が終わったら元の値に戻すよ。
- 元の値が空だった場合は、空に戻したことをAPIで読み直して確認するよ。
- 保存の確認が取れるまでは、テストだと言って終わらせないよ。
