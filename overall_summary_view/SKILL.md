## 決まった手順

- ひとさんが「全体の集計を見せて」「未収は誰がいる？」「○○さんはどれくらい来ている？」と聞いたら、`全体集計` シートをAPIで読んで答えるよ。

## 全体集計の見方

- 3行目が設定の見出し、4行目が設定の値だよ。A4=開始年月、B4=集計月数、C4=最大行数、D4=表示モードだよ。
- 5行目が終了年月の見出し、6行目が終了年月だよ。
- 期間は2026/01〜2026/12だよ。タロちゃんが変えたよ。前は2026/10〜2027/09だったよ。
- 氏名は顧客マスタのB列から引いているよ。だから、あだ名で出るよ。
- 8行目がヘッダーで、9行目からデータだよ。

| 列 | 内容 |
|---|---|
| A | TimeTree名 |
| B | 氏名 |
| D | 出席回数 |
| E | キャンセル回数 |
| F | 合計回数 |
| G | 未収額 |
| H | 入金額 |
| I | 合計金額 |
| J | 出席率 |
| K | キャンセル率 |
| L | 未収率 |
| M | 平均単価 |
| N | 最終来店日。来たことがない人は空だよ |
| O | 最終制作物 |
| P | 未収フォロー。来たことがない人は空、来ていて未収がある人は「要フォロー」、来ていて未収がない人は「通常」だよ |

- N列は、来たことがない人が1899/12/30になっていたのを、2026-11-23に直したよ。見つからないときは0を返して、0が日付で1899/12/30になっていたからだよ。今は空になるよ。
- P列の見出しは、2026-11-23に「予約状況」から「未収フォロー」に変えたよ。中身は未収のフォローだからだよ。

## 表示モード

- D3に「表示モード」、D4に「全員」か「対象者」が入っているよ。D4はドロップダウンで、クリックで切り替えられるよ。
- 「対象者」は、期間内にTimeTreeの予定がある人だけだよ。2026/01〜2026/12では9人だよ。
- 「全員」は、マスタ全員（27人）だよ。
- 期間を変えると、対象者に出る人が変わるよ。

## 空になるルール

- 「全員」モードで、D（出席回数）もE（キャンセル回数）も0の人は、DからPまで全部空になるよ。
- 「対象者」モードでは、そういう人は出てこないよ。
- だから、空の行は「来ていない人」だよ。

## 伝え方

- 期間と表示モードを最初に伝えるよ。「2026/01から12カ月、対象者モードだよ」のように。
- 未収を聞かれたら、P列が「要フォロー」の人を、未収額（G列）と一緒に伝えるよ。合計も伝えるよ。
- 入江さんのように入金済みの人は、「入金済みで未収は0円だよ」と伝えるよ。
- タロ.AI はテストの予約だよ。未収に出ていても、テストだと伝えるよ。
- 出席0の人が多いのは、まだテストだからだよ。そう伝えるよ。
- 人数を伝えるときは、「○名いるよ」と伝えるよ。
- ○○さんを聞かれたら、その人の出席回数・未収額・最終来店日・最終制作物を伝えるよ。

## 期間を変えるとき

- ひとさんが「1年分を見せて」「半年分を見せて」と言ったら、A4（開始年月）とB4（集計月数）を変えるよ。B4は月数だよ。
- ただし、TimeTreeシートに入っているデータの期間しか集計できないよ。2026-11-23の時点では、TimeTreeシートには2026/11/02〜12/05の21件しかないよ。1年分や全期間を見るには、まず「TimeTreeを取り込む」で scrape04all をして取り込み直す必要があるよ。
