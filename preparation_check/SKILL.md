# 当日の作業を確認する

## 対象

- スプレッドシートは atelier顧客データベースで、IDは `14XTckRGgkSI8TQay-eemw25183iHGz-LaNmC9fyVF7g` だよ。
- 見るシートは `事前準備` だよ。
- 確認はGoogle SheetsのAPIで読むだけだよ。GASの新しい action は要らないよ。

## 決まった手順

- ひとさんが「今日の作業を確認して」「11月9日の準備を見て」と言ったら、その日の作業を確認するよ。
- `事前準備` シートをAPIで読んで、日付ごとの制作物・TODO・請求額・支払済を伝えるよ。
- TODOがまだ終わってないものと、請求が必要なものを分けて伝えるよ。

## 事前準備シートの見方

- B2が表示開始日、C2が表示期間（日数）だよ。たとえばB2が2026/11/01、C2が30なら、11/01から30日分が表示されるよ。
- 4行目がヘッダーで、5行目からデータだよ。

| 列 | 内容 |
|---|---|
| A | 教室日時 |
| B | TimeTree名 |
| C | 氏名 |
| D | 作業予定 |
| E | 制作物 |
| F | TODO（「:」付きで改行つなぎ） |
| G | TODO済（はい／空。直接編集しない） |
| H | 請求額 |
| I | 支払済額 |
| J | 請求要否（請求要！／入力要！／空） |

- G列（TODO済）は、TimeTree編集のB21（TODO済）を保存した結果が表示される列だよ。事前準備シートでは直接編集しないよ。
- I列（支払済額）は、TimeTree編集のB20（入金済）を保存した結果が反映されるよ。
- J列が「請求要！」なら、請求額があってまだ支払われていないよ。
- J列が「入力要！」なら、請求額も支払済額も0で、まだ何も入っていないよ。2026-11-23に、空の行は「入力要！」と出るように変えたよ。

## 期間を変えるとき

- B2に開始日（YYYY/MM/DD）、C2に期間（日数）をAPIで書くだけでいいよ。
- 書いたら、シートの表示が変わるよ。GASは要らないよ。

## 伝え方

- 日付ごとに、名前・制作物・TODOの件数と内容・TODO済かどうか・請求額・支払済額を伝えるよ。
- TODOが空の行は、「まだ何も入ってないよ」と伝えるよ。入れ忘れか、わざと入れていないかは、聞いて確認するよ。
- 請求額があって支払済が0円のものは、「請求要だよ」と伝えるよ。

- なお、同日にタロがデータを入れ替えたため、この日より前の例（堀内先生にデータあり、入江さんは空）はもう古いよ。
