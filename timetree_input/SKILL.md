# 予約を入れる

## 対象

- スプレッドシートは atelier顧客データベースで、IDは `14XTckRGgkSI8TQay-eemw25183iHGz-LaNmC9fyVF7g` だよ。
- 入力するシートは `TimeTreeデータ登録` だよ。
- TimeTreeへの登録は、ウェブアプリの `input01` でやるよ。

## 決まった手順

- ひとさんが「○月○日 ○時〜○時 名前 内容」と言ったら、その予約をTimeTreeに入れるよ。
- まず `TimeTreeデータ登録` シートの2行目に、予約の内容を入れるよ。
- 次にウェブアプリの `input01` を呼ぶよ。TimeTreeに登録されるよ。
- 呼び出しの返答が `ok:true`（起動の受付）なら、「入れたよ」と伝えるよ。登録のログは確認しないよ。
- TODOと請求書も一緒に言われたときは、予約を入れたあと、カルテ編集で入れるよ。下の「予約と一緒にTODO・請求書を入れるとき」を見てね。TODOと請求書が無いときは、予約だけで終わりだよ。

## シートへの入力（2行目）

1行目はヘッダーだよ。2行目に入れるよ。

| 列 | 入れるもの | 例 |
|---|---|---|
| A | 予約年月日（YYYY/MM/DD） | 2026/11/05 |
| B | スタート時間（HH:MM） | 20:00 |
| C | エンド時間（HH:MM） | 21:00 |
| D | タイトル（お客様） | タロ.AI |
| E | メモ（作業内容） | クリスマス制作 |
| F | 画像URL | ドライブの共有URL（画像が無いときは空） |
| G | 色ラベル | Pastel brown（必ずこれ） |
| H | 入力するGoogleドライブ | ガラス教室_画像入力（すでに入っている） |

- 色ラベルは必ず `Pastel brown` にするよ。これじゃないと、取り込みで拾われないよ。
- 画像があるときは、ドライブの「ガラス教室_画像入力」フォルダへアップして、リンク共有にしてからURLをFに入れるよ。共有なしだと、取り込み側が画像をダウンロードできないよ。
- 画像が無いときは、Fは空でいいよ。

## ウェブアプリで登録する方法（2026-11-22に確認）

- ベースURLは `https://script.google.com/macros/s/AKfycbw0xvM-620l1MwSccqYieFewNR-K20etKAIj1K-Cp6Hg5UQnrvpj2r4PmIi0fl3Jw9A/exec` だよ。
- GETで呼ぶよ。`{URL}?action=input01` の形だよ。curlでは `-L` を付けてリダイレクトをたどるよ（`curl -sL`）。
- `-L` なしだと返答が空になるよ。でも空でも登録は走っていることがあるよ。2026-11-26に `-L` なしで呼んだら空返答だったのに dispatch されていて、もう一度呼んだら同じ予約が2回登録されたよ。返答が空でも、まず `LOG_Actions` と100行目以降のログを確認して、dispatchされていれば再実行しないよ。
- 返答は「起動を受け付けた」という意味で、完了待ちじゃないよ。成功すると `{"ok":true,"action":"input01","result":{"ok":true,"http":204,"runId":"...","runUrl":"..."}}` が返るよ。
- `runUrl` で進み具合を見られるよ。`LOG_Actions` シートでも確認できるよ。
- `dry_run` は付けないよ。`input01` は本番保存だからだよ。
- 社長には action や URL を書かせないよ。自然な言葉から日付・時刻・名前・内容を組み立てるよ。
- 登録が成功すると、その週だけ自動で取り込み（scrape）が走るよ。数分かかることがあるよ。取り込みは毎日16:00にも自動で動くよ。
- 取り込み（scrape01）を手動で呼ぶのは、入力のときはしないよ。時間がかかるからだよ。自動の取り込みを待つよ。TimeTreeシートに行がなかなかできないときだけ、タロちゃんに聞いてから手動で呼ぶよ。

## 聞くこと

- 日付・名前・開始時刻・終了時刻・内容の5つが要るよ。
- 開始と終了の時刻が無いと入れられないよ。日付だけではできないから、時刻だけは必ず聞くよ。
- 日付や名前が多少間違っていても、シートと照らして「この人で合ってる？」と確認してから入れるよ。
- 内容が決まってないときは、内容だけ聞くよ。
- TODOと請求書は、あれば一緒に聞くよ。無ければ聞かないよ。TODOは3つまで、請求書は内容と金額のセットで4つまでだよ。

## 入力済みの行の扱い

- 新しい予約を入れるときは、2行目の古い内容を消してから入れるよ。
- 入力済みの行を残したまま `input01` を呼ぶと、重複して入るかもしれないよ。まだ確認していないことだよ。
- 入れ終わった行は、`TimeTree` シートに行ができたのを確認してから空にするよ。まだ読まれてないうちに消すと、登録されないことがあるからだよ。登録の記録は100行目以降のログに残るから、消しても大丈夫だよ。

## 登録できたかの確認

- input01の確認は、`TimeTreeデータ登録` シートの100行目以降の登録ログを見ないよ。ログの確認は待つのが遅いから、やめたよ（2026-11-27にタロちゃんが決めた）。
- 呼び出しの返答が `ok:true`（起動の受付）なら、「入れたよ」と伝えるよ。
- 本当に登録できたかは、`TimeTree` シートに行ができたのを見るよ。行ができるのは自動取り込みのあとだよ。カルテ編集に進むときや、次に確認するときに見るよ。
- `TimeTreeデータ登録` の2行目は、TimeTreeシートに行ができたのを確認してから空にするよ。まだ読まれてないうちに消すと、登録されないことがあるからだよ。次の予約のときは、古い内容が残っていたら消してから入れるよ。
- `LOG_Actions` シートでも、実行の結果を確認できるよ。

## 予約と一緒にTODO・請求書を入れるとき（2026-11-27に確認）

- ひとさんが予約と一緒にTODOや請求書を言ってきたら、ひとつのお願いの中で、順番にまとめて入れるよ。
- 1. 「予約を入れる」の手順で `input01` を呼ぶよ。
- 2. 自動の取り込みを待って、`TimeTree` シートに行ができたのを確認するよ。手動の取り込み（scrape01）は呼ばないよ。行ができたら、`TimeTreeデータ登録` の2行目を空にするよ。
- 3. カルテ編集の手順で、ウェブアプリの load（GET）で読み込むよ。labelは「日時＋半角スペース＋名前」だよ（例：`2026/11/25 15:00 タロ.AI`）。
- 4. B18（制作物）に作品名を入れるよ。予約のときのメモ（作業内容）と同じものを入れるよ。
- 5. TODO（C32〜）と請求書（B50・C50〜）をAPIで書き込むよ。TODOは3つまで（C32・C33・C34）、請求書は内容と金額のセットで4つまで（B50・C50〜B53・C53）だよ。
- 6. ウェブアプリの save（GET）で保存するよ。
- 7. `TimeTree` シートの該当行で、制作物（I列）・TODO（E列）・請求額（F列）・TODO-No（Y列）・請求書No（AY列）を確認して、ひとさんに伝えるよ。
- 新しい予約なら、loadでTODOと請求書が戻ってこない問題は起きないよ。まだ何も入ってないからだよ。
- 細かいやり方は「カルテ編集して保存する」の「予約とまとめて入力するとき」にも書いてあるよ。
- 確認した例：2026-11-27に「2026/11/25 15:00 タロ.AI ステンドグラス、TODO 事前準備A・B・C、金額 A 1,000円・B 2,000円・C 3,000円・月謝 5,000円」で試したよ。カルテIDは2、データ行は5。合計12,100円、TODO-No T-2、請求書No INV-2026-11-24-2 になったよ。
